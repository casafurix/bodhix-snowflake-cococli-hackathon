# Snowflake CoCo CLI Hackathon — Problem Statements

> **Participants are required to select and build a solution for _any one_ of the four problem statements.**
> All four are built on **Snowflake CoCo CLI** and center on AI-native, agentic solutions over enterprise data.

---

## 01 — Intelligent Workflow Automation Agent

Build an AI-driven system that can understand enterprise data and autonomously execute multi-step workflows using Snowflake CoCo CLI.

Your solution should go beyond simple querying and demonstrate reasoning over data to identify anomalies, generate insights, and trigger contextual actions. The system should support decision-making in real-world scenarios such as **operations, finance, supply chain, or customer support**.

**Participants are encouraged to:**
- Identify a business problem with measurable impact
- Build 2–3 modular Agent Skills or custom skills
- Orchestrate these skills into a complete agentic workflow
- Demonstrate a fully working end-to-end workflow executed through the CLI

**Judging Focus**

- **Real-World Relevance**
  - Does the workflow solve a clearly defined business problem?
  - Is the use case grounded in a realistic operational context with measurable impact?
- **Technical Execution**
  - Does the solution demonstrate multi-step orchestration?
  - Does it handle errors and decision branches effectively?
  - Does it make strong use of Snowflake CoCo CLI, Agent Skills, and tools?
- **Solution Completeness**
  - Is the workflow fully end-to-end, from data ingestion and reasoning to actionable output?
  - Does it operate with minimal manual intervention?

---

## 02 — Unstructured Data Intelligence System

Design a solution that can extract, interpret, and derive insights from unstructured data such as **contracts, reports, support tickets, logs, or mixed-format documents**, and combine it with structured data for deeper analysis.

Using Snowflake CoCo CLI, your system should demonstrate contextual understanding and enable users to interact with data in a meaningful and actionable way.

**Participants are encouraged to:**
- Select a realistic unstructured data source tied to a business use case
- Parse and enrich content using AI capabilities
- Integrate structured and unstructured data pipelines
- Deliver insights or actions based on the processed information

**Judging Focus**

- **Real-World Relevance**
  - Does the solution address a genuine business need using realistic data sources?
- **Technical Execution**
  - Does the system effectively ingest, parse, extract, and enrich unstructured content?
  - Does it demonstrate strong integration between structured and unstructured data workflows?
- **Solution Completeness**
  - Does the solution cover the full lifecycle from ingestion and processing to queryable and actionable output?

---

## 03 — AI-Native Data Application

This hackathon focuses on building AI-native data applications using Snowflake CoCo CLI.

Build a fully functional application on **Snowflake's AI Data Cloud** that enables users to interact with enterprise data using natural language.

The application should generate insights, summaries, and recommendations through a seamless user experience where AI is deeply integrated into how users explore and act on data.

**Participants are encouraged to:**
- Solve a concrete user problem
- Build an intuitive natural language interface
- Use Snowflake CoCo CLI to orchestrate data retrieval and reasoning
- Deliver a cohesive end-to-end application experience

**Judging Focus**

- **Real-World Relevance**
  - Does the application solve a meaningful problem that real users would adopt?
- **Technical Execution**
  - Is the natural language interaction accurate, contextual, and robust?
  - Does the application demonstrate effective skill orchestration, retrieval, and error handling?
- **Solution Completeness**
  - Can users move from question to insight to action within a single integrated experience?

---

## 04 — Domain-Specific AI Copilot

Create an AI copilot tailored to a specific industry such as **healthcare, finance, retail, manufacturing, agriculture, or education**.

Using Snowflake CoCo CLI, the copilot should understand domain-specific context and data, support realistic workflows, and provide actionable recommendations rather than generic responses.

**Participants are encouraged to:**
- Select a well-defined industry use case
- Incorporate domain terminology, constraints, and decision patterns
- Build Agent Skills or custom skills aligned to the workflow
- Demonstrate a complete decision-support experience

**Judging Focus**

- **Real-World Relevance**
  - Is the copilot grounded in authentic industry workflows and business requirements?
- **Technical Execution**
  - Does the solution use domain-appropriate data, guardrails, and effective CoCo CLI orchestration?
- **Solution Completeness**
  - Can the copilot handle the full workflow from context gathering to recommendation and user action?

## Common Threads Across All Four

| Theme | Detail |
|-------|--------|
| **Platform** | All built on Snowflake CoCo CLI / Snowflake AI Data Cloud |
| **Beyond querying** | Reasoning, insights, anomalies, actions — not just data retrieval |
| **Agent Skills** | 2–3 modular / custom Agent Skills orchestrated together |
| **End-to-end** | Full lifecycle: ingestion → reasoning → actionable output |
| **Measurable impact** | Grounded in a realistic business problem with real users |

**Shared judging pillars:** Real-World Relevance · Technical Execution · Solution Completeness
